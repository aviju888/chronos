# Modern interface attribution

The standalone Chronos interface adapts the user-owned Chronos component source and shared craft helpers from the avijuan-lab source snapshot recorded in `licenses/modern-source-manifest.json`. The destination has no runtime dependency on that source project.

The extracted color tokens and effects derive from Beautiful UI (beautifului.dev), distributed under the included `Beautiful-UI-LICENSE.txt` (MIT).

Inter Variable and Inter Variable Italic are bundled with `public/fonts/modern/Inter-OFL.txt`. JetBrains Mono Regular is bundled with `public/fonts/modern/JetBrainsMono-OFL.txt`. Both font families use the SIL Open Font License.

Geography data is packaged locally by world-atlas; its package and the other dependencies retain their upstream package licenses.
